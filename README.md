# CodeAlpha_CollabMeet

A real-time video conferencing and collaboration application built using the MERN stack.

## Features

- User Registration and Login
- JWT Authentication
- Create and Join Meetings
- Real-Time Video Calling using WebRTC
- Screen Sharing
- Real-Time Chat
- File Sharing
- Collaborative Whiteboard
- Meeting Access Authorization

## Technologies Used

- React.js
- Node.js
- Express.js
- MongoDB
- Socket.IO
- WebRTC
- Tailwind CSS
